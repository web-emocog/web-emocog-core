# Handoff checklist для frontend

Документ используется перед переводом макета из `Ready for review` в `Ready for development`.

## Ответственность

- Ответственный за дизайн: Валерия.
- Исполнитель production frontend: Аня.
- Изменения API и контрактов согласуются с Юлей.
- Изменения participant runtime согласуются с Егором.

## Передача экрана

- [ ] Экран имеет ID из архитектуры: `R0-R14` или `P1-P8`.
- [ ] Указаны desktop, tablet и mobile layout.
- [ ] Указан route и существующий или планируемый component/file.
- [ ] Определено одно главное действие.
- [ ] Все интерактивные элементы используют компоненты дизайн-системы.
- [ ] Описаны hover, focus, active, disabled, loading и error.
- [ ] Есть loading, empty, error и permission state.
- [ ] Для данных описаны no-data, low-confidence, off-screen и degraded state.
- [ ] Demo/mock данные визуально обозначены.
- [ ] Текст не содержит диагностических обещаний.
- [ ] Для таблиц и графиков предусмотрено mobile-представление.
- [ ] Проверены keyboard flow и focus order.
- [ ] Contrast соответствует WCAG AA.
- [ ] Тексты готовы на русском; места расширения для английского учтены.

## Перед реализацией

- [ ] Аня подтвердила route/component mapping.
- [ ] Юля подтвердила API fields и permission states.
- [ ] Егор подтвердил participant lifecycle и названия QC/signal states.
- [ ] Валерия зафиксировала макет и версию tokens.
- [ ] Спорные вопросы записаны в Issue, принятое решение добавлено в описание.

## Проверка реализации

- [ ] Реализация не добавляет второй набор несвязанных CSS tokens.
- [ ] Production UI не содержит inline-значений, если существует token.
- [ ] Layout проверен на `1440`, `1200`, `900`, `768` и `390px`.
- [ ] Основной сценарий проходит только клавиатурой.
- [ ] При `prefers-reduced-motion` нет обязательной анимации.
- [ ] Нет FOUC, layout jump и горизонтального scroll страницы.
- [ ] Loading не вызывает повторную отправку действия.
- [ ] Error state сохраняет введённые данные, если это безопасно.
- [ ] No data не отображается как нулевое значение.
- [ ] Скриншоты реализации приложены к PR.
- [ ] Visual regression покрывает критический desktop и mobile flow.

## Мини-отчёт

После выполнения implementation-задачи в Issue указываются:

- внесённые правки;
- новые технические включения;
- особенности реализации;
- решения спорных вопросов;
- команды тестов и browser/device matrix;
- отличия от макета;
- обновлённая документация;
- остаточные риски.
