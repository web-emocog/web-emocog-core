# SVG-макеты WEC

Минималистичный набор экранов для переноса в Figma.

## Состав

- `32` экрана исследователя: `R0-R14`, регистрация, desktop и mobile.
- `26` экранов участника: `P1-P8` и критические варианты состояний.
- `3` системных SVG: дизайн-система, состояния desktop и mobile.
- `screens/manifest.json` - перечень всех экранов и путей.
- `index.html` - локальная галерея.
- `functional-audit.md` - проверка покрытия функций.
- `check.mjs` - проверка XML-структуры, размеров и контраста.

Всего: `61` SVG-файл.

## Визуальный принцип

- Только одна главная кнопка на экран.
- Иконная навигация без повторяющихся подписей.
- Поясняющий текст оставлен только там, где он влияет на решение или согласие.
- Тёмный teal задаёт структуру.
- Бирюзовый используется для primary actions и успешных измерений.
- Синий используется для аналитики, selection и data layers.
- Красный используется только для ошибок и блокирующих состояний.
- Оранжевый используется только для предупреждений.
- Фиолетовый используется как дополнительный слой данных, а не статус.
- Жёлтый используется как high-contrast highlight внутри тёмных панелей.
- `no-data`, `low-confidence` и `off-screen` не маскируются.

## Импорт в Figma

1. Открыть нужную папку в `screens/`.
2. Перетащить SVG на canvas Figma.
3. Не выполнять `Flatten`, если нужно редактировать отдельные элементы.
4. После импорта проверить наличие `Golos Text` и `IBM Plex Mono`.
5. Сгруппировать экран во Frame с исходным размером:
   `1440x900` для desktop или `390x844` для mobile.
6. Переименовать Frame по имени файла, например `R6 · Конструктор · Desktop`.

SVG не содержит внешних изображений, ссылок и зависимостей.

## Просмотр

Из корня репозитория:

```bash
python3 -m http.server 8088
```

Открыть:

```text
http://localhost:8088/docs/design/sprint-1/svg/
```

## Повторная генерация

```bash
node docs/design/sprint-1/svg/generate.mjs
node docs/design/sprint-1/svg/check.mjs
```

Все изменения вносятся в `generate.mjs`, после чего набор генерируется заново.
