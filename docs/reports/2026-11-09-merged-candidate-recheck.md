## Проверка Linux и границы совместимости

- Сервер: свежий Linux ARM64 API-образ, Node 22, PostgreSQL 16. Все 80
  интеграционных проверок прошли, без пропусков. Тесты включают роли,
  изоляцию, согласия, квоты, конвертацию, версии, запись и удаление.
- Linux Chromium: все 132 выбранные проверки интерфейса/сохранения прошли
  до перехода исходного общего процесса к Firefox.
- Linux Firefox/WebKit: отдельный прогон завершился 264/264, по 132 в
  каждом движке. Вместе с Chromium проверены по 132 выбранных сценария
  на каждом из трёх движков Linux. Модельные Worker/WebGL тесты сюда не
  переносились и как Linux GPU-приёмка не засчитывались.
- Использован официальный образ Playwright `v1.57.0-noble`, совпадающий
  с версией зависимости проекта, без внешней сети. Chromium 143.0.7499.4,
  Firefox 144.0.2, WebKit 26.0. Это настоящие Linux-процессы в контейнере,
  не подмена user-agent macOS-браузера.
- Первый Linux Firefox завис при запуске с read-only домашним каталогом;
  диагностический запуск с временным `HOME=/tmp` успешно поднял Firefox
  и WebKit. Защита браузеров и код сайта ради этого не отключались.
- В ранних SQL-прогонах тестовый tmpfs был меньше требуемого резерва
  конвертации, не был подключён writable uploads и срабатывали штатные
  лимиты запросов на большой набор фикстур. Достаточный временный диск,
  отдельные тестовые лимиты и неизменяемый тестовый образ дали 80/80.
  Production-пороги диска и rate limiting не ослаблялись.

На Windows нет доступного реального устройства/виртуальной машины.
Windows/Edge, установленный Safari с настоящей камерой и мобильные ОС
не объявляются проверенными только по Playwright. Linux на Mac не даёт
