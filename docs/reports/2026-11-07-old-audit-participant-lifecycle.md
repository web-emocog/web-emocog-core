# Старый аудит: жизненный цикл страницы участника

Локальный кандидат `feature/signal-quality-profiles`, 7 ноября 2026 года.
Ничего не опубликовано на GitHub или production. Физические камера и микрофон
не использовались; ответы API и потоки в новых тестах искусственные.
Исходная таблица Google Sheets не изменена.

Закрыты строки старого аудита **43, 50, 51, 73**; строка **81** переведена в
частичное выполнение. Из исходных 239 строк теперь 105 исправлены в текущем
или локальном коде, 62 неактуальны/не подтверждены, **72 остаются**, включая
пять частичных. Это не заявление об отсутствии всех ошибок продукта.

## Изменения

| Строка | Исправление и граница |
| --- | --- |
| 43 | Рисование можно отменить до начала и во время выполнения. Снимаются клавиатурные обработчики, таймер и анимация. Отмена не создаёт результат, событие успешного завершения или продолжение очереди тестов. Нормальное нажатие «Завершить» по-прежнему сохраняет результат. Невлияющие на данные catch диагностики/focus оставлены. |
| 50 | Ошибка admission больше не оставляет необработанное отклонение обработчика согласия. Повторное нажатие и смена галочки не запускают второй запрос. Отмена страницы прерывает admission и ожидание сетевого повтора; восстановление использует те же ID и исходное приглашение. Отказ хранилища при возврате не вызывает автоматическую перезагрузку с потерей данных: доступны повтор и JSON. |
| 51 | Очистка перенесена с ненадёжного beforeunload на pagehide. Снимаются обработчики документа, RT, таймеры checkpoint, локальные циклы взгляда/валидации/слежения и предпросмотра. Останавливаются камера, микрофон и контроль FPS; поздний результат старого анализа не возрождает цикл. Активная страница, вернувшаяся из истории, проходит восстановление, а не продолжает старую пробу с остановленной камерой. |
| 73 | Повтор отправки финального результата обрабатывает техническое отклонение: показывает сообщение, возвращает доступность кнопки и сохраняет исходный пакет. Захват прекращается до ожидания очереди аудиоанализа. Ошибка снимка физиологии не мешает остановке остальных модулей; повтор остановки не дублирует сводки. |
| 81, частично | UI учитывает незавершённый admission и отменённую страницу, не переходит дальше после ухода, сохраняет понятную ошибку при повторе. После восстановления браузером состояния галочки кнопка согласия пересчитывается. Асинхронный старый запуск после оболочки теперь ожидается, но для исключения в ветке без пречека остаётся только диагностический ответ: отдельный экран восстановления и адресный тест ещё нужны. |

При уходе не вызывается finish и не выделяется номер финальной доставки.
Принятые RT сохраняются, прерванная проба не добавляется как принятая.
Финальный документ при возврате из кеша истории остаётся пригоден для
скачивания и повторной отправки. При отказе хранения старый измерительный
экран заблокирован, но отдельные кнопки восстановления/экспорта доступны.

Прерывание permission-запроса не закрывает системный диалог за пользователя.
Если поток приходит после отмены, его tracks сразу останавливаются и не
прикрепляются к странице. Старт калибровки проверяет отмену и после ожидания
готовности моделей, и после инструкции.

## Данные и совместимость

- Веса, научные методы, пороги QC, частоты инференса, статистика и состав
  отправляемых измерений не менялись. Новый benchmark точности/FPS не заявлен.
- API endpoints, права, схема БД и миграции не менялись. Admission transport
  принимает необязательный AbortSignal; session/participant/invitation tuple
  и идемпотентность сохраняются.
- Сырые аудио/видео не добавлены в логи или API. Ошибки новых обработчиков
  выводят фиксированные диагностические коды, не текст серверного ответа.
- HTML и взаимозависимые модули выпускаются согласованно с
  `20261107-5`, включая аудиоадаптер и рисование; старые отдельные JS не
  следует выкладывать поверх нового HTML.

## Что Не Подтверждено

Браузер сам решает, сохранять ли конкретный документ в кеше истории.
Искусственные persisted-события доказывают обработку ветки, но не поддержку
такого кеширования для каждого реального протокола на каждом устройстве.
Реальный переход «Назад» проверен отдельно без требования определённого
способа кеширования.

При закрытии процесса ОС не обязана завершить последнюю асинхронную запись.
Периодические контрольные точки остаются обязательными. Возврат при отказе
хранения защищён от автоматического сброса, но не от принудительного
закрытия вкладки самим пользователем. Окно аудио, ещё не принятое анализом
до закрытия процесса, не объявляется гарантированно сохранённым.

Не проводились новая проверка сайта, реальные длинные записи, измерение
энергопотребления, научная валидация и приёмка на проблемных устройствах.
Пункты #132/#144/#146 не закрываются одним этим техническим проходом.
