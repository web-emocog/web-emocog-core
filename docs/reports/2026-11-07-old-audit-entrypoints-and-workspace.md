## Проверки и ограничения

- 882 проверки API прошли, 8 условных пропусков; отдельно 77/77 PostgreSQL
  на свежей тестовой БД. RT Python, TypeScript, release-audit и diff check прошли.
- 60/60 адресных браузерных проверок, 351/351 staff regression и 3 условных
  пропуска (покрыты отдельным live-прогоном), 48/48 staff HTTP, 33/33 HTML security.
- 36/36 конструктор, 156/156 библиотека стимулов, 39/39 адресная аналитика и
  7/7 основной набор аналитики.
- Реальный API в Chromium, Firefox, WebKit: 3/3 совместная публикация со
  стабильной ссылкой, 33/33 доступы/медиа/тепловые карты, 21/21 приём результатов,
  перезагрузка, обрыв сети и повтор без дубликатов.
- Итоговый веб-образ: 259 разрешённых файлов, 404 для старых JS, относительные
  переходы с no-referrer/no-store. 15 переходов через Nginx проверены в трёх
  браузерных движках, включая сохранение legacy fragment. 52/52 теста выпуска.
- В первом прогоне быстрое переключение выявило дублирующий render, после
  исправления точное число запросов проверяется. Две нестабильности более
  широкого прогона устранены ожиданием фактического ответа списка и завершения
  начальной загрузки библиотеки перед подстановкой тестовых данных.

Измерительные пороги, веса моделей, форматы БД и API-права не менялись.
Браузеры работали с локальными фикстурами и отдельной тестовой PostgreSQL.
Камера и микрофон не включались. Отсутствие новых ошибок в тестах не заменяет
проверку физической камеры, Safari на целевом устройстве и релизную приёмку.

Проверки выпуска: согласованно выпускать HTML, общий parser, кабинет и
Nginx. На готовом артефакте проверить сохранение query старой ссылки и 404
устаревших модулей. Для отката достаточно предыдущего согласованного
веб-образа и его Nginx-конфигурации; миграции и данные не затронуты.
