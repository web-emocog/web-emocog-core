# Старый аудит: приватность диагностики участника

Локальный кандидат `feature/signal-quality-profiles`, без публикации, правок
исходной таблицы, реальных аккаунтов и физической камеры. Закрыты восемь строк:
`152, 154, 179, 182, 189, 192, 196, 198`. Сводка: 101 исправлена в текущем или
локальном коде, 62 неактуальны/не подтверждены, **76 остаются**, включая
четыре частичные.

| Строки | Проверенный результат |
| --- | --- |
| 152, 154 | FACS lifecycle больше не пишет ID сессии в консоль. Необязательная диагностика ошибок получает только фиксированный код. Оценки и веса не менялись. |
| 179, 182 | Запуск, ошибка приглашения и подпись согласия не выводят URL, hash и исключения в прямую консоль. В событии ошибки начальной загрузки сохраняется только HTTP-статус, а не текст ответа. Хеш согласия по-прежнему создаётся и проверяется штатно. |
| 189, 192 | Убраны прямые логи переходов между блоками и повторяющихся ошибок анализа. Доступность камеры, остановка/повтор, реальные измерения FPS и существующий учёт качества остаются в штатных каналах. |
| 196 | Не логируются полные сводки проверки качества и тело ошибки отправки. Категория ошибки заменяет текст сервера и в локальном состоянии, чтобы следующий JSON не содержал это эхо. Отправка, сообщение и повтор с исходным ключом сохранены. Сводка дыхания строится только для включённой диагностики. |
| 198 | Идентификаторы больше не выводятся в консоль при согласии. При синхронном сбое скачивания JSON показывается сообщение; ссылка и временный Blob URL освобождаются, повтор доступен. |

Измерительные пороги, схемы БД и права не менялись. В браузерных URL согласованно
обновлена версия модулей, чтобы кеш не загружал два экземпляра циклических
зависимостей. Уже скачанные JSON и старые локальные записи не мигрируются;
это исправление новых записей, а не автоматическая анонимизация. Встроенные
сообщения браузера о сетевых запросах и журналирование в непроверенных модулях
не отменены.

- 21 целевая Node-проверка приватности, подписи и FACS. Полный набор API:
  885 прошли, 8 условных пропусков, 0 ошибок. В первом прогоне изолированный
  VM стенд пречека не подхватил новый импорт; после передачи реального
  диагностического модуля все 18 проверок пречека и весь набор API прошли.
- 312/312 в Chromium, Firefox и WebKit. Проверены согласие, пречек, калибровка,
  выбор профиля, загрузка и восстановление, скачивание. Синтетическое значение
  из ответа 403 не появляется ни в консоли, ни в сохранённом состоянии даже
  при включённой диагностике. После перезагрузки повторяется тот же пакет
  с тем же ключом. Сбой нажатия скачивания освобождает Blob, повтор работает.
- 132/132 проверки Workers, запуска моделей и диагностического lifecycle;
  99/99 проверки FPS, дубликатов, попыток и физиологических интервалов.
  Оба набора прошли в Chromium, Firefox и WebKit без физических датчиков.
- Веб-образ собран, 260 разрешённых файлов; Nginx smoke, проверка TypeScript,
  RT Python, статический release-audit и diff check прошли.
