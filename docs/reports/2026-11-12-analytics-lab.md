# Расширенная аналитика: локальный стенд

## Назначение

Добавлены 40 видов сводок из уже сохраняемых данных. Сбор камеры, микрофона,
инференс, параметры и веса моделей не изменены. ML, диагнозы, распознавание
стресса и подтверждение точности физиологии в эту работу не входят.

Интерфейс сохраняет оформление WECog: крупные показатели, кольцевая карта
доступных сводок, силуэт с переходами к каналам, распределения, парные линии,
диаграмма переходов взгляда и карты доступности. Кольцо показывает наличие
расчётов, а не оценку когнитивного состояния человека.

## Состав

| Раздел | Что добавлено | Условия расчёта |
| --- | --- | --- |
| R1–R2 | Разброс реакции, коэффициент вариации, медиана и квантили | Корректные ответы с сохранённым числовым временем реакции |
| R3 | Доли ответов быстрее/медленнее заданных границ | Границы задаёт исследователь, скрытых нормативов нет |
| R4 | Изменение реакции по ходу задания | Сохранены порядок и время; это не диагноз утомления |
| R5 | Скорость и точность ответов | Известна правильность ответа; отсутствие ответа не заменяет нулевое RT |
| R6 | Разница между выбранными условиями/блоками | Явно выбраны A и B; сравниваются совпадающие участники |
| R7 | Реакция после ошибки | Только соседние сопоставимые пробы; разрывы, перезагрузки и неоднозначные попытки исключаются |
| R8 | Попадания, пропуски, ложные тревоги, d′ и критерий ответа | Явно указаны условия ответа/удержания; для d′ применяется поправка 0,5 ко всем четырём ячейкам |
| G1–G2 | Рейтинг зон и достижение цели | Сохранены полные фиксации и AOI нужной версии; сессии, затем участники взвешены поровну |
| G3 | Направленные переходы взгляда | Сохранён порядок полных фиксаций; ширина связи — число переходов, не корреляция |
| G4 | Последовательность целей | Порядок явно задан в AOI; не угадывается по расположению элементов |
| G5 | Энтропия распределения взгляда | Есть сохранённая пространственная сетка; это не «концентрация внимания» |
| G6 | Карта группы | Сопоставимые стимул, блок, система координат и метод; участники взвешены поровну |
| F1 | Сводки пульса и дыхания | Только доступные, опубликованные, не удержанные оценки |
| F2 | Отличие от исходного уровня | Исследователь выбрал исходный блок; есть сопоставимые интервалы |
| F3 | Минутная/блочная динамика | Есть сохранённые интервалы; график разделяет людей, каналы и разрешение времени |
| F4 | Изменение в блоке восстановления | Выбраны исходный блок и блок восстановления; непрерывная длительность восстановления не измеряется |
| F5–F7 | Характеристики морганий, движения/позы, мимики | Только уже сохранённые характеристики; мимика не приравнивается к достоверно установленным эмоциям |
| A1–A2 | Акустические характеристики и их динамика | Принятые аудиоокна с известным блоком и временем; распознавание речи не добавлено |
| A3 | Баллы опросников | Явные баллы вариантов, границы и обратные пункты; текст преобразуется в число только по отдельному разрешению |
| A4 | Ответы и время заполнения | Сохранены события ответов; свободный текст не отражается в сводках |
| A5 | Самооценка и другие измерения | Шкала и показатель присутствуют в одной сессии; статистическую связь можно проверить в S5 |
| S1 | Парное сравнение / независимые группы | Парный t-критерий / Welch; единица анализа — участник |
| S2 | Ранговые сравнения | Wilcoxon / Mann–Whitney; для трёх и более условий Friedman / Kruskal–Wallis |
| S3–S4 | Размер различия, доверительные интервалы, повторная выборка | Два сравниваемых уровня; повторная выборка участников с сохранённым начальным значением генератора |
| S5 | Связь двух показателей | Pearson или Spearman; полные пары индивидуальных значений, не отдельные кадры/пробы |
| S6 | Множественные проверки | Заранее выбранное семейство; Holm, Bonferroni или Benjamini–Hochberg; отсутствующая гипотеза не уменьшает семейство |
| S7 | Согласованность повторных измерений | Явно сопоставлены визиты A/B; одинаковые протокол/версия/методы, завершённые полные записи; ICC(A,1) |
| Q1 | Завершение зарегистрированных сессий | Не включает неизвестные отказы до регистрации участника |
| Q2 | Чувствительность к сохранённым правилам качества | Сравнение существующих статусов, без повторного анализа видео |
| Q3 | Устройства/браузеры и доступные показатели качества | Только сохранённые категории; отсутствующие сведения не угадываются |
| Q4 | План и зарегистрированное предъявление | Браузерная длительность, не аппаратная точность физического появления стимула |
| Q5–Q6 | Доступность каналов и происхождение результатов | Отдельно от достоверности измерения; учитываются усечения и версии методов |
| Q7 | Плоские признаки для собственной статистики | Участник, сессия, блок/условие, показатель, единица, статус; ограничения экспорта помечаются |

## Важные ограничения

- Сессионная средняя не переносится на выбранный отдельный блок или AOI.
- Для фильтра условия взгляд соединяется с пробой по сохранённой идентичности
  предъявления; отсутствие условия в самой записи взгляда не удаляет подходящий показ.
- Для AOI-фильтра контекст попыток сохраняется для проверки качества, но RT
  не объявляется измеренным «внутри AOI».
- Повторные сессии одного участника не увеличивают число независимых людей.
- Общая диаграмма R2 показывает распределение сохранённых сессионных медиан/
  квантилей, а не восстановленное распределение всех исходных RT.
- Разрывы физиологии не интерполируются. На одной линии не смешиваются
  дыхание, пульс, разные люди или минутные и блочные интервалы.
- Некоторые небольшие выборки/вырожденные данные не позволяют получить
  корректное p. В этом случае p отсутствует, а не заменяется 0 или 1.
- Диаграмма переходов G3 считает все подходящие переходы до ограничения
  числа отображаемых групп; не обрезает начало длинной выборки до агрегации.
- Не рассчитываются HRV из среднего пульса, истинные эмоции, клинические
  состояния, SSRT из обычного Go/NoGo, причинные связи и результаты ML.

## Интерфейс и экспорт

1. Выбрать протокол, версию и выборку, нажать «Применить».
2. Нажать сектор кольца, точку силуэта или карточку раздела.
3. Нажать точку/столбец/связь графика: открыть соответствующие наблюдения.
4. Для сравнения выбрать условия либо непересекающиеся группы. Для трёх и
   более условий необходимы полные парные наблюдения или независимые люди
   в каждом уровне, без повторного использования одного человека в разных группах.
5. Изменённые настройки нужно пересчитать или отменить. До пересчёта старые
   результаты скрыты; переходы между разделами не уничтожают черновик незаметно.
6. JSON сохраняет план, выборку, версии, признаки, наблюдения, методы и
   диагностику. CSV содержит одну строку на участника, число его сессий и
   показатели по столбцам. Повторные сессии одного участника усредняются с
   равным весом; пустая ячейка означает, что оценка отсутствует.
7. PNG скачивает текущий график; PDF использует действующий механизм текущего
   отчёта. Перед экспортом сервер повторно проверяет право доступа/экспорта.

## Архитектура и безопасность

Расчёты: `apps/api/analytics/extended-features.js`, `extended-statistics.js`,
`extended-worker.js`, `extended-service.js`. API: POST
`/analytics/v1/extensions/run` и `/analytics/v1/extensions/export`.
Их нельзя использовать без авторизации и доступа к закреплённой выборке.

Снимок выборки и права проверяются заново, включая попадание в кэш.
Запрос не принимает произвольные массивы данных от клиента. Настройки имеют
закрытую вложенную схему. HTML/SVG-подписи экранируются, CSV защищён от формул.
Ответы не кэшируются браузером. Фоновые расчёты выполняются в отдельном потоке
Node, а не в основном потоке интерфейса или сбора камеры.

Ограничения одной расширенной выборки: 100 сессий, 16 МиБ входных данных,
192 МиБ памяти рабочего потока, 20 секунд, один активный расчёт и очередь
из четырёх. До 500 детальных строк на сводку, до 12 000 признаков. Достигнутые
ограничения отражаются в интерфейсе и экспорте; для более подробного просмотра
нужно сузить выборку. Большие сетки групповой карты укрупняются с сохранением массы.

## Локальный стенд

Адрес: `http://127.0.0.1:4212/apps/web/researcher.html#/analytics/group-comparison`.
API на 3012, отдельная временная PostgreSQL. Существующие порты
3000/4173/5432 не изменяются. Стенд явно подписан как синтетический.
Имя cookie стенда отдельное: вход в тестовый аккаунт не заменяет cookie
основной локальной системы на том же адресе.
Сгенерированы 20 участников, две сессии каждого, повторные попытки,
пропуски, низкое качество, RT, AOI, физиология, аудиопризнаки и анкеты.
Камера, микрофон и отправка в интернет не используются.

Запуск из корня рабочего дерева с уже собранными локальными Docker-образами:

```bash
bash apps/autotests/scripts/start-analytics-lab.sh
```

Скрипт отказывается заменять существующие контейнеры. Файл с данными для
входа создаётся с правами 0600 в непубличной временной папке; её путь записан
в `/private/tmp/wecog-analytics-lab-current`. Секретный файл не входит в Git
или публичную сборку. База стенда временная: остановка удаляет только её
синтетические записи, не пользовательские данные основной системы.

## Проверки

```bash
cd apps/api
npm test
node --test tests/extended*.test.js
```

```bash
cd apps/autotests
npm run typecheck
ANALYTICS_LAB_FIXTURE="$(cat /private/tmp/wecog-analytics-lab-current)/private/analytics-lab.json" \
  npx playwright test --config=playwright.analytics-explorer.config.ts
```

Численные тесты сравнивают результаты с независимыми контрольными примерами
R/SciPy и опубликованными примерами ICC; источники указаны в тестах.
Сквозная проверка автоматически выполняется при запуске изолированного стенда
(`ANALYTICS_LAB_VERIFY=YES`) сразу после заполнения синтетическими сессиями,
без чтения учётных данных из файла и без записи полного ответа API на диск.
Она отдельно пересчитывает среднее RT, проверяет все 40 сводок
в подходящих конфигурациях, независимые группы, равенство экспорта и отчёта,
отказ другому исследователю и неавторизованному клиенту.

Проверки браузеров относятся к движкам Chromium, Firefox и WebKit на текущем
стенде. Они не являются проверкой физических Windows/Linux-устройств,
FPS камеры или научной точности измерений на людях.

## Уточнение интерфейса после проверки 12 ноября

- Кольцевая карта находится только в общем обзоре. На вкладках качества данных
  и связности она не повторяется. Сектор выбирается нажатием или клавиатурой;
  описание и основные значения остаются в отдельной панели справа.
- Прежняя схематичная фигура в динамике сессии убрана. Выбор пульса и дыхания
  остаётся в обычном списке каналов, график использует всю ширину.
- Списки показателей сортируются по видимым названиям, с учётом языка.
- Для сохранённых оценок реакции, физиологии, морганий, позы и мимики добавлен
  выбор распределения либо значений по сессиям. Оценка одного канала не
  смешивается с другим; дубли сводки и диапазона одной сессии не удваивают N.
  Повторные сессии не объявляются независимыми участниками.
- Обновление выбранной точки/ряда сохраняет положение прокрутки и раскрытые
  настройки. Фоновая загрузка не должна пересоздавать неизменившиеся графики.
- Техническая плашка «Данные API» убрана, состояния ошибок и авторизации сохранены.
- CSV дополнительно проверяется обратным чтением: одинаковое число столбцов,
  одна строка на участника и совпадение сводных значений с JSON.

### Проверка отчётов и восстановления

- PDF формируется из закреплённой выборки и расчётов, а не из текста всех
  элементов страницы. Кольцо, силуэт, формы, навигация и внутренние поля не
  выгружаются. Есть крупные результаты, статические распределения, парные
  графики, интервалы и таблицы статистических сравнений. PDF показывает подписи
  выборки; идентификатор и полный план остаются в JSON.
- В «Мои графики» можно добавить до 12 отдельных представлений. Сглаживание
  не заполняет разрывы. Кластеры группируют значения одного показателя и не
  определяют типы участников. Каждое представление скачивается в PNG, а все
  добавленные графики входят в PDF текущего отчёта. Настройки входят в JSON;
  смена выборки или перезагрузка очищает рабочую подборку графиков.
- PDF повторно проверяет разрешение экспорта. Изменение выборки, аккаунта
  или плана во время формирования отменяет устаревшую выгрузку. Несчитанные
  настройки нельзя выдать за новые результаты. Сбой декодирования картинки
  имеет ограниченное время ожидания и не заменяет данные вымышленными.
- Отдельная проверка обнаружила и исправила несовпадение двух идентификаторов
  сессии: фильтр API содержит номер строки БД, а экспорт сохраняет публичный
  UUID. Поэтому выбор одной сессии больше не обнуляет расширенные сводки.
  Версия расчёта повышена до `analytics-extensions.2`.
- После обновления сохраняются положение страницы и выбранные графики только
  для того же аккаунта, адреса, выборки и набора данных. Позиция не применяется
  к изменённым данным. Особенность Firefox с типом перехода учтена отдельно.
- Малые вероятности не округляются визуально до нуля. Пропуски и нечисловые
  значения остаются отсутствующими данными; числовой экспорт не меняется.

Последняя проверка: 1200 серверных тестов прошли, 10 условных проверок
пропущены штатным запуском; 27 проверок нового интерфейса и 30 прежних
сценариев аналитики прошли в Chromium, Firefox и WebKit. Отдельно проверено
обновление сетки тепловой карты при сохранении её DOM-элемента без повторных
обработчиков/наблюдателей. PDF группы и одной сессии отрисованы и просмотрены;
JSON/CSV перечитаны и сопоставлены с результатами API. Это техническая проверка
на синтетических данных, не научная валидация модулей или проверка реальных
устройств с Windows/Linux.
