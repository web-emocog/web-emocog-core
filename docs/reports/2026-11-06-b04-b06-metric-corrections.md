## Версии и данные

- Поза: `body_pose_mediapipe.v2`, метод угла
  `camera_normalized_axis_modulo_180.v2`. Зеркальность меняет знак наклона,
  а не его модуль; перестановка концов оси не добавляет 180°.
- Это угол в нормированных координатах камеры, не откалиброванный
  анатомический угол. Соотношение сторон и перспектива остаются ограничениями.
- Новые суммы и число пригодных углов хранятся отдельно в
  `shoulderAxisAbsSum` / `shoulderAxisValidCount`. Старый
  `shoulderRollAbsSum` не меняется и не смешивается с новой средней.
- Сводка содержит `shoulderRollMethod`, `shoulderRollSampleCount` и
  `shoulderRollLegacySampleCount`. При отсутствии измеримого угла средняя
  равна `null`. Старые результаты сохраняют прежнюю версию метода.
- VPC: `vpc_image_aoi.v2`, пространство `content_viewport_css_px`, сигнал
  `corrected`, области `rendered_image_content_rect`.
- В каждой фактически подготовленной пробе сохраняются ID, исходный путь,
  размер, SHA-256 и атрибуция использованного файла; временные Blob URL
  в результаты не попадают. Декодирование UI-изображений завершается
  до начала отсчёта экспериментальных фаз.
- Результат VPC содержит `valid`, `reason`, `coverageFraction`,
  `trackingCoverageFraction`, `unknownDurationMs`, `outsideImageMs`,
  `gapCount`, реальные границы областей и окно предъявления.
- Между двумя последовательными пригодными наблюдениями в одной области
  допускается интервал не более 250 мс. Непригодная точка разрывает
  наблюдение; длинный интервал не обрезается до 250 мс и не засчитывается.
  Переходы между областями и края окна без наблюдений не экстраполируются.
- `noveltyPreferencePct=null` для невычислимой или исключённой пробы.
  Причины: `invalid_window`, `stimulus_unavailable`, `layout_changed`,
  `image_aoi_unavailable`, `no_valid_observation`, `insufficient_coverage`.
  При скрытии вкладки во время предъявления результат исключается.
- Сводка исключает placeholders, невалидные и старые неверсионированные
  пробы. Есть `invalidTrials`, `skippedTrials`, `exclusionReasons` и
  `legacyUnscoredTrials`. Старые сводки автоматически не переписываются.
- Значения времени и долей покрытия не округляются до нуля в сохранённых
  данных. Отсутствие данных не заменяется нулевым предпочтением.

## Проверки и воспроизведение

Среда: macOS / arm64, Node.js 25.4.0, Playwright 1.57.0. Использованы
синтетические координаты и существующие локальные изображения. Камера,
микрофон и production-данные не использовались.

```bash
# Из корня репозитория
cd apps/api
node --test tests/metric-corrections.test.js
npm test

cd ../autotests
npm run typecheck
npx playwright test -c playwright.metrics.config.ts
```

- Полный набор Node: 779 проверок, 772 успешны, 7 пропущены, 0 ошибок.
  Пропуски относятся к окружению PostgreSQL/внешних утилит/Linux/nginx,
  а не к новым проверкам расчётов. Интеграционные наборы PostgreSQL,
  отмеченные пропуском целого набора, также этим запуском не подтверждены.
- Новый файл расчётов: 13 проверок, включая сохранность версий и `null`
  при сборке итогового JSON и проверке его действующей схемой API.
- Браузеры: 21/21 успешно, без повторов; по семь сценариев в Chromium,
  Firefox и WebKit. Исполняются настоящий VPC runner, загрузчик, проверка
  файлов и CSS на изолированной странице. Время фаз ускорено часами теста,
  но загрузка/декодирование файлов выполняются реально.
- Проверены отсутствие необработанных ошибок, очистка источников изображений
  и освобождение всех созданных Blob URL после каждого полного запуска.
- Проверка типов и `git diff --check` успешны.
- Добавлен обязательный запуск Chromium/Firefox в существующий release gate
  и WebKit в существующий необязательный macOS workflow. Дублирующий запуск
  этого набора из общего конфигурационного файла исключён.
- Исходный сценарий воспроизведения аудита теперь даёт горизонталь 0° и
  ноль пригодных пустых VPC-проб. Старый вызов без реальных image AOI
  отклоняется, а не получает вымышленное предпочтение. Разрыв с правильной
  новой геометрией отдельно покрыт модульными тестами.

В браузерной проверке найдены и исправлены два сопутствующих дефекта:
повторное декодирование изображений в Firefox и выход рамки изображения
за ширину узкого экрана. Обновлены версии URL модулей и CSS, чтобы старый
кэш не смешивал методы и раскладки.

## Границы закрытия

Это закрытие технических B04–B06, не научная валидация и не выпуск продукта.
Положительное покрытие означает только вычислимость VPC. Научно обоснованный
минимум покрытия не выдуман: текущая политика требует положительного
наблюдения и сохраняет `suitability=research_only_not_validated`.
Общая проверка качества записи не означает подтверждённой точности метрики.

Не изменены веса моделей, частоты инференса, Worker-распараллеливание,
число VPC-проб, порядок пар и экспериментальные длительности. Новых
изображений и лицензий не добавлено. Миграция БД не нужна; поля версий
и качества передаются внутри существующих объектов данных.

Независимая разметка позы, эталонный gaze benchmark, обоснование покрытия,
методический паспорт VPC, физическая точность времени предъявления и
проверка на людях остаются отдельными задачами C02/C06/C08/C09.
