# Аналитика WECog: интерфейс и сверка с ТЗ 5.1

## Решения по интерфейсу

- Обзор, график, детали по запросу. Участник, объём выборки и результат
  видны до таблиц и алгоритмов. Паспорт отчёта сохраняет хеш, версии и метод.
  Основания: [Dashboard Design Patterns](https://dashboarddesignpatterns.github.io/),
  [Tableau](https://help.tableau.com/current/blueprint/en-us/bp_visual_best_practices.htm)
  и [Nielsen Norman Group](https://www.nngroup.com/articles/progressive-disclosure/).
- Одна точка на человека для групповых распределений. Временные оценки
  показаны отдельными интервалами; разрывы не интерполируются. Цвет дублируется
  подписями и формой, данные качества отделены от результата измерения.
  Основания: [Observable Plot](https://observablehq.com/plot/features/marks),
  [Datawrapper](https://www.datawrapper.de/blog/which-color-scale-to-use-in-data-vis)
  и [ONS](https://service-manual.ons.gov.uk/data-visualisation/guidance/showing-uncertainty-in-charts).
- В связанности отдельно показаны временная шкала и диаграмма связи.
  Таблица проб доступна по раскрытию. Сопоставление по событиям не означает
  причинность. Тепловые карты и области интереса остаются отдельным
  пространственным представлением, как в [Tobii Pro Lab](https://tobii.my.site.com/s/article/heat-maps-and-gaze-plots?language=en_US).

## Сверка с требованиями

| Раздел | Реализовано | Не реализовано и почему |
| --- | --- | --- |
| Сессия | Минуты, попытки блоков, пробы RT, интервалы ЧСС/дыхания, распределение правильных валидных RT, тепловые карты. | Нет полного непрерывного многоканального ряда и режима запланированных повторов. У имеющихся данных неодинаковая детализация; QC-повтор не равен запланированному. |
| Контракт блоков | Публикация, сессия, участник, события и попытки там, где их поддерживает исходная запись. | Единый сквозной `blockInstanceId` и `repeatIndex` для всех типов блоков, включая старые данные. Нужен версионированный контракт записи, а не восстановление идентичности из имени. |
| Группа | Точки участников, распределения, парные линии, разность B − A, N/n, поисковый 95% ДИ для RT; описательное сравнение ЧСС и дыхания между блоками или независимыми группами. | Нет универсального маршрутизатора моделей, подтверждающих тестов, семейств поправок, LME/GEE/GLMM, survival для TTFF и моделей временной зависимости. Требуются сопоставимые наблюдения, план гипотез, диагностика и контрольные расчёты. |
| Качество | Каналы, доля валидных наблюдений, причины, сохранённая пространственная проверка взгляда, ограничения отчёта. | Не для всех каналов доступны частота, максимальный разрыв и точное временное покрытие по каждому блоку. Без исходных временных данных их нельзя вывести достоверно. |
| Связанность | RT и один выбранный сигнал по пробам одной сессии, окна до/до ответа/после. В разделе группы можно выбрать два доступных показателя: значения сопоставляются по участнику, а не позиции в массиве; показана описательная ранговая связь. | Нет повторных корреляций, лагов и подтверждающих межмодальных моделей. Нужны сопоставимые интервалы, синхронизация и модель зависимости. |
| Экспорт | CSV/JSON одной зафиксированной выборки, PDF текущего отчёта, PNG новых SVG-графиков с проверкой права экспорта. Воспроизводимый экспорт сессии сохранён отдельно. | PNG не добавлен к старым тепловым картам и связанности; нет полного экспорта результатов ещё не реализованных моделей. |
| Справочник | Поиск основных обозначений в интерфейсе. | Не все термины имеют подсказку прямо на месте. Термины будущих методов не добавлялись в основной экран. |
| ML | Не подключён по согласованному приоритету. | Для него потребуются независимые данные и проверка без пересечения участников. |

Новые графики используют только данные отчёта по применённой выборке. Число
валидных ответов в распределении RT может быть меньше числа засчитанных проб:
неверные ответы, пропуски и недоступные RT не входят в распределение.

## Дополнительная проверка 10 ноября

- В основных графиках используются названия блоков, стимулов и областей,
  псевдонимы участников или порядковые номера вместо UUID. Исходные
  идентификаторы остаются в данных для воспроизводимости и технических деталях.
- Увеличены результаты и элементы управления, сокращены основные пояснения.
  Ограничения измерений сохранены, но подробности раскрываются по запросу.
  Ссылки на научные статьи убраны из основного экрана связанности.
- Выбор точки, полосы, участника, диапазона и переходы с клавиатуры проверены.
  Значения без измерений не подменяются нулями; неправильные ответы и
  незасчитанные пробы не включаются в распределение правильного RT.
- ЧСС/дыхание: сравнение блоков читает только засчитанные попытки с сохранёнными
  интервалами и достаточным наблюдаемым временем. Участники имеют одинаковый
  вес; повторные сессии сначала усредняются внутри участника. Короткие окна
  вокруг нажатия для этого сравнения не используются. Интервалы и методы
  сохраняются в экспорте; p-value для физиологии не вычисляется.
- Незавершённые старые каналы физиологии не обрушивают отчёт и не добавляют
  вымышленные оценки. Валидация новых записей на входе не ослаблялась.
- Найден и исправлен отдельный дефект проверки типов запроса сравнения:
  нестроковый код метрики мог вызвать исключение вместо штатного отказа.
  JSON-схема и серверный список поддержанных метрик синхронизированы;
  версия аналитического расчёта повышена до `analytics-api-1.3.0`.
- Контракт ответа дополнен фактически используемыми единицами фоновых
  сигналов. Тест сверяет его с единицами каталога метрик.
- Отчёт прежней версии расчёта нельзя пересчитать новым кодом под старой
  отметкой версии: сервер возвращает 409, интерфейс скрывает прежние результаты
  и предлагает заново применить ту же выборку. Поздние ответы параллельных
  запросов не возвращают устаревшие графики. Данные сессий не удаляются.
- Старые неподдерживаемые коды метрик и фильтров не отправляются повторно из
  сохранённого черновика. Пользователь получает понятное предложение сбросить
  несовместимые фильтры. Это устраняет известный сценарий ошибки запроса,
  но не доказывает причину того самого 422: действие и ответ не были записаны.
- Вход защищён от повторного запроса во время отправки и перехода на другую
  страницу. При 429 показывается ожидание, в том числе если время ожидания
  пришло в JSON, а не заголовке. Серверные ограничения входа не увеличивались.

## Границы проверки

Автотесты браузеров не подтверждают FPS реальной камеры или точность
физиологии на людях. Linux проверяется в контейнере ARM64 с контролируемыми
источниками кадров. Для Windows добавлен отдельный ручной запуск
`windows-runtime-smoke.yml`, но на Windows эти изменения пока не запускались.
На данном Mac нет среды Windows. Подтверждение совместимости на реальных
проблемных устройствах остаётся отдельной приёмкой.

Локальный рабочий сайт: `http://127.0.0.1:4173/apps/web/researcher.html`.
Пример интерфейса на вымышленных данных: порт 4217 с `?analyticsPreview=1`.
Файл примера исключён из публичной сборки; на рабочем локальном сайте он
возвращает 404. База, пользовательские стимулы и пароли не сбрасывались.

Изменения пока локальные. Для отката к прошлой версии интерфейса достаточно
использовать предыдущую сборку static frontend; для API сохранён предыдущий
локальный контейнер. Миграции рабочих данных для этих изменений не нужны.
