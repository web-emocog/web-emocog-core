# Issue #143: ложная остановка при старте диагностики в Windows

## Причина и исправление

На Windows/Chrome тест остановился с `viewport_changed` в фазе `calibration`,
после 42 обработанных кадров без ошибок и до первого калибровочного клика.
Старый контроллер останавливал запуск по любому событию `visualViewport.resize`.
В Chromium с классической полосой прокрутки удалось воспроизвести тот же отказ:
при скрытии инструкции ширина `visualViewport` выросла с 1521 до 1536 CSS px,
хотя размер окна, DPR 1.25 и масштаб visual viewport 1 не изменились. Такое
поведение соответствует [CSSOM View](https://www.w3.org/TR/cssom-view/):
ширина видимой области не включает классическую полосу прокрутки.

Ревизия `20261109-143n` сначала скрывает preview и убирает прокрутку измерительного
экрана, затем фиксирует его фактическую геометрию и создаёт трекеры. Координаты
центров берутся через общий `targetCenterInContentViewport`. Событие без изменения
размеров, offset, масштаба или DPR не останавливает тест. Реальное изменение
по-прежнему завершает запуск с `viewport_changed`, останавливает камеру и
предлагает скачать незавершённый JSON с исходной геометрией измерения. При остановке
подписки снимаются, прокрутка восстанавливается. До старта измерения можно
менять размер окна; системный масштаб Windows сбрасывать не нужно.

Меняется только developer benchmark и его локальный аналог. Модели, пороги,
последовательность целей, participant flow, API, схема JSON и миграции не
изменены. Новые данные не собираются; авторизация и локальная обработка сохранены.
Изменение не является проверкой точности gaze или устранения дрейфа.

## Проверки и выпуск

- На прежнем контроллере новая регрессия с классической полосой прокрутки
  воспроизвела `viewport_changed`; на исправленном — показана первая точка,
  камера работает, а Esc останавливает её и возвращает прокрутку.
- `gaze-benchmark.spec.ts`: 43 passed, 2 skipped (проверка классической полосы
  только для Chromium). Chromium/Firefox/WebKit: неизменная геометрия не
  останавливает тест, реальный resize и имитация изменения масштаба останавливают.
- `issue143-gaze.spec.ts` в WebKit: 13 passed, включая полные синтетические
  проходы spatial/posture/temporal и запуск/остановку локального экрана.
- Node: 103 passed, 0 failed (`gaze-benchmark`, `issue143-*`, `gaze-signal`).
  TypeScript typecheck и `git diff --check` прошли.

Проверка классической полосы была на Chromium с DPR 1.25, не на физическом
Windows-устройстве. После штатного выпуска нужен повтор короткой программы в
Chrome на машине тестировщицы с прежними настройками. В JSON проверять
`benchmark.revision=20261109-143n`. Для отката достаточно вернуть этот
frontend-патч; данных и БД откат не касается.
