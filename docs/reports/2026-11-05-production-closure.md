# Локальная проверка готовности wecog

Область проверки: публичная регистрация, загрузки, большие протоколы,
длительные сессии и эксплуатационная безопасность. Использованы
изолированная PostgreSQL 16, синтетические стимулы и адреса. Не использованы
production, камера, микрофон или настоящая отправка писем.

## Результаты

| Область | Изменение и проверка |
| --- | --- |
| Квоты медиа | Резервирование места до multipart, учёт версий и превью, ограничения на организацию, пользователя, общий параллелизм и свободный диск. Конкурентные запросы не обходят квоту. |
| Неизвестный результат записи | Ключ операции привязан к пользователю и содержимому. Ответ зафиксированной операции можно повторно прочитать. Сбой связи после COMMIT не удаляет сохранённые файлы; обрыв до завершения multipart удаляет частичный файл и освобождает резерв. |
| Большие протоколы | Подготовка только нужного блока; бюджет управляемых бинарных данных 256 МиБ на кэш, с учётом временных копий. Активные файлы защищены от вытеснения. Проверены наборы 63/360 файлов, 429, смена версии, восстановление подготовки и отсутствие сетевой подмены файла во время пробы. |
| Длительное измерение | IndexedDB сохраняет приращения вместо повторной записи полного массива. Проверены 40 и 125 минут ускоренных синтетических данных, прерывание транзакции, перезапуск браузера и сохранность результата. Подробности в `2026-11-05-long-session-stress.json`. |
| Лимиты API | Два независимых HTTP-сервера делят общий атомарный счётчик PostgreSQL. При отказе счётчика запрос не пропускается без лимита. |
| Диагностика | Идентификатор запроса для сопоставления с обезличенными ошибками; агрегированные метрики только для ролей admin и developer. |
| Резервное восстановление | Клиент PostgreSQL 16 в Docker. Снимок восстановлен в новую БД; совпали данные 25 таблиц и SHA-256 двух версий файла и одного превью. Повреждённый исходник отклонён. Миграции 1–21 проверены циклом up/down/up на пустой базе. |
| Регистрация | Email до пароля, одноразовые ссылки, локальная доставка, изоляция организации и проектов, отзыв старых сессий при сбросе. Сквозной HTTP-тест: два аккаунта, приглашение в проект, приватный файл, восстановление операции и публикация. |

## Что не доказано

- Бюджет кэша не является лимитом на всю память браузера: память декодера и GPU
  в него не входит. Если целый блок не помещается, пробы не стартуют и
  интерфейс предлагает повторить подготовку; потоковая загрузка во время проб
  не включается. После перезагрузки медиа нужно подготовить заново.
- Проверка длительности ускоренная, плюс короткий сценарий с реальными часами
  и искусственной задержкой. Не проверены двухчасовая сессия с физической
  камерой, сон ОС и малопамятные устройства. Исходный массив `eyeSignals`
  растёт; для его ограничения без потери результатов нужен потоковый
  расчёт и проверка эквивалентности итоговых метрик.
- Квота относится к файлам, не к общему объёму БД. Для публичного запуска
  нужны мониторинг заполнения диска и очереди, политика очистки и внешние
  ограничения трафика. Удаление опубликованных файлов не выполняется для
  освобождения места.
- Локальный почтовый режим проверен. Настройка отправителя, доставка через
  реальный SMTP и DNS домена ещё не проверены. Публичная регистрация выключена.
