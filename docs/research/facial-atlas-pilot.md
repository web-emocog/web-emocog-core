## Запуск

Из корня проекта: `node local-harness/serve.mjs`.
Открыть `http://127.0.0.1:8080/apps/web/developer/facial-atlas-test.html`.
Нужен обычный работающий API и вход admin/developer; статический сервер сам по
себе не обеспечивает авторизацию. Настройка API — штатная для developer tools.
Если локальный фронт уже работает на 4173, использовать тот же путь на этом порту.
Обновить страницу без кеша после изменения общего pipeline.

1. Запустить камеру, пройти штатную подготовку выбранного профиля (по умолчанию v2).
2. Закрыть левый глаз, проверить Left/Right и явно выбрать ориентацию входа.
3. Указать псевдонимы и выбрать зоны. По умолчанию выбраны обе половины губ.
4. Начать отдельную нейтраль атласа. Все каналы выбранных зон обязательны.
5. После готовности начать пробу; менять выражение и наблюдать канал/график/таблицу.
6. Завершить блок и скачать JSONL. Остановка камеры также завершит запись.
   Перед новым блоком скачать предыдущий. Не закрывать страницу до скачивания.

## Явные пилотные настройки

Частота по умолчанию 20 Гц, выбирается 5–30 Гц до записи. Обработчик получает
готовые primary frames; один исходный кадр на capture-time slot, без интерполяции.
Целевая частота не гарантирована: показывается отдельно от достигнутой частоты.
Знаменатель покрытия остаётся заданным, не уменьшается при пропусках.

Нейтраль — последнее окно 5 с (настраивается 5–20 с), минимум 25 качественных
отсчётов на каждый канал; максимальный разрыв max(300 мс, 2.5 интервала).
При низкой частоте окно можно явно увеличить перед новым блоком. Дольше 30 с
нейтральная запись не продолжается; неготовность имеет причину и экспортируется.
После начала пробы база замораживается. Ограничение нейтрального MAD не задано:
порог не выбирался на независимых данных. Текущая пригодность использует качество
лица, освещения, позы, свежую сегментацию и геометрию зоны; геометрия не доказывает
отсутствие окклюзии. Ручной тест очков/руки обязателен перед исследованием.

Вывод: absolute, baseline, signed delta, число нейтральных отсчётов, MAD, причины.
Для выбранного канала — график последних 200 записей и сводка 2 с с покрытием
65%, max gap max(250 мс, 2.5 интервала). Пропуск остаётся null; длинные разрывы
графика не соединяются. Эти параметры не являются научной приёмкой.

JSONL ограничен 1200 кадрами или 24 МиБ сериализованных строк. Лимит включает
нейтраль; при 20 Гц это около минуты. В памяти дополнительно находятся bounded
объекты этих записей для просмотра. Заголовок сохраняет модель/hash, версии,
ориентацию, настройки, калибровку, границы фаз и причину остановки.
Не сохраняются изображения, landmarks или идентификаторы реальной published session.
Это локальный диагностический блок, не контракт данных исследования.

## Границы этапа

Справочная карта 18 зон открывается отдельно; она ещё не связана с временными
рядами исследовательской сессии. Таблица и график каналов находятся в диагностике.
API ingest, кабинет исследователя, события стимулов, новые эмоциональные индексы,
эпизоды и асимметрия не включены. Старые алгоритмы сохраняют свои версии.
Не применять исходный integration patch поверх текущего runtime.

## Проверки

`node --test apps/api/tests/facial-atlas.test.mjs`

Из `apps/autotests`: `npx playwright test --config playwright.facial-atlas.config.ts`.
На Windows конфигурация использует установленный Edge, на других ОС — Chromium.

Браузерные тесты `apps/autotests/tests/facial-atlas.spec.ts` используют
синтетический поток для проверки управления и экспорта. Они не доказывают
точность на лицах или производительность камеры. Реальная проверка: нейтраль,
одностороннее закрытие глаза, улыбка, потеря лица, рука, поворот, остановка и
повторный запуск, сравнение FPS с выключенной и включённой записью.
