Дыхание при реальных стимулах (~7 минут)

Всё считается на этом компьютере по одним и тем же кадрам; на сервер ничего не отправляется. Включите звук (лучше наушники).

Что будет

  1. Покой — серый экран, 1,5 мин.
  2. Фото на тёмном фоне (фон задачи по умолчанию): фото 1 с, затем крестик 1–2 с, 2 мин.
  3. Фото на светлом фоне: так же, 2 мин.
  4. Пассивный просмотр: фото 4,3 с, пустой тёмный экран 4,3 с (≈7 смен/мин — худший случай), 1,5 мин.

Всё время дышите под звук: тон вверх — вдох, тон вниз — выдох, 12 вдохов в минуту. Метод, который везде показывает ≈12, видит дыхание; который совпадает с ритмом экрана — ловит экран. Сидите спокойно, смотрите на экран как в задаче, не разговаривайте. Желательно, чтобы плечи были в кадре.

Камера выключена.

Результат

Появится после прогона. Учитываются оценки с 25-й секунды каждого этапа (окну оценки нужно 20 с).

Методы

AТекущий: яркость кожи (v2)
PНовый метод сайта: медиана D1, D2c и плеч (или масштаба лица), с вычитанием яркости щёк вместо яркости экрана; публикуется при согласии 2 из 3
CЯркость щёк минус известная яркость экрана
D1 / D2 / D3Движение головы: переносица / наклон / масштаб лица
EДвижение плеч (модель позы), если плечи видны
D2c / D3c / EcТо же движение после вычитания известной яркости экрана
KМедиана D1, D2c, Ec (с известной яркостью экрана — эталон для P)
