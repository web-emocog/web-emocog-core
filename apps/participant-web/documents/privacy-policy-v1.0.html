1. Какие данные мы собираем

Тип данных Примеры Цель сбора
Демографические Возраст, пол, родной язык Анализ групп участников
Технические Разрешение экрана, тип браузера, ОС Контроль качества данных
Поведенческие Координаты взгляда, время реакции, моргания Оценка внимания и когнитивных функций
Контактные Email (зашифрован SHA-256) Связь с участником по результатам
🔒 Мы НЕ собираем:
  • Видеозаписи вашего лица
  • Фотографии
  • Аудиозаписи
  • Данные банковских карт
  • Паспортные данные

2. Как мы защищаем ваши данные

  • Шифрование: Все данные передаются по HTTPS/TLS
  • Обезличивание: Email хешируется (SHA-256), ID генерируется случайно (UUID v4)
  • Локальная обработка: Видео анализируется в браузере, не отправляется на сервер
  • Ограниченный доступ: Только авторизованные исследователи видят обезличенные данные
  • Раздельное хранение: Email хранится отдельно от данных исследования

3. Ваши права (GDPR)

Вы имеете право:

  • 📄 Доступ: Запросить копию ваших данных
  • ✏️ Исправление: Исправить неточные данные
  • 🗑️ Удаление: Запросить удаление данных (в течение 30 дней после сессии)
  • ⛔ Ограничение: Ограничить обработку ваших данных
  • 📤 Портируемость: Получить данные в машиночитаемом формате (JSON)

Для реализации своих прав напишите на: privacy@emocog.com

4. Срок хранения данных

  • Данные сессий: 5 лет (для научных публикаций)
  • Email: До вашего запроса на удаление или завершения проекта
  • Агрегированные данные: Бессрочно (полностью обезличены)
