# wecog brand mark

The mark combines a lowercase `w`, an eye-movement path and a single focus point.
It uses one continuous, balanced construction so it remains recognizable at favicon size
and can be reproduced from memory without a grid.

## Files

- `wecog-mark.svg`: standalone mark for navigation and icons.
- `wecog-logo.svg`: horizontal wordmark for wide surfaces.
- `fonts/atkinson-hyperlegible-next.woff2`: local variable UI font.
- `fonts/ATKINSON-OFL.txt`: SIL Open Font License 1.1.

## Rules

- Do not rotate, stretch or add effects to the mark.
- Keep clear space equal to the diameter of the focus point.
- Use the lime focus point only for brand and positive/active states, not as decoration.
- The participant UI stays light and uses the accent only for controls, never for stimuli.
