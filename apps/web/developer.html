Pre-check

Precheck (камера, лицо, освещение)

Проверка готовности: освещение, лицо в кадре, поза. Калибровка и кнопка «Начать калибровку» после прохождения.

Открыть модуль Precheck
BPM / rPPG

BPM (пульс по видео)

Оценка ЧСС по видео лица (rPPG). Требует камеру и стабильное лицо в кадре.

Открыть тест BPM
Emotion Module

Emotion Test (valence/arousal)

Тестирование эмоционального модуля из participant flow: live-метрики valence/arousal, динамика на таймлайне.

Открыть Emotion Test
Reaction Time

Reaction Time (Go/NoGo)

Кликер: считывание нажатий (Space/клик), лог в формате rt_component. Go/NoGo без MVP — только проверка аналитики и считывания. Скачать JSONL и прогнать через rt_component-/scripts/analyze_log.py.

Открыть RT-тест (кликер) Полный модульный Hub
Gaze / Tracking

Gaze-on-target и Tracking

Калибровка взгляда и тест слежения: откроется сразу тестовый hub (без лэндинга респондента).

Открыть модуль Tracking/Hub
QC Metrics

QC Metrics (качество сигнала)

Модуль качества: точки взгляда, валидность, offscreen. Автотесты без камеры.

Открыть тест QC
Приглашения

Ссылки-приглашения для участников

Создание ссылок на пречек (камера, калибровка, тесты). Участник переходит по ссылке и проходит проверку условий и калибровку.

Создать ссылку-приглашение
Experiment Accounting

Учет экспериментов

Сводка по экспериментам и последние сессии: статус, QC, приглашения, completed/in_progress.

Открыть учет экспериментов
